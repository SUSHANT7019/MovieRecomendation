Understanding Set Operations

Union (∪)

Combines all unique elements from both sets. If an element appears in either set, it's in the union.

Intersection (∩)

Contains only elements that appear in both sets. This is the overlap between sets.

Difference (−)

A - B contains elements in A but not in B. Order matters: B - A gives different results.

Symmetric Difference (△)

Elements in either set but not in both. It's like XOR for sets.

Jaccard Similarity

Measures how similar two sets are. Range: 0% (no overlap) to 100% (identical sets).
